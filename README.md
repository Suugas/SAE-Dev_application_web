L'objectif du projet est de pouvoir poster et noter des messages et images sur un mur commun entre plusieurs utilisateurs.
Les utilisateurs ont également la possibilité de se suivrent entre eux afin de voir les messages postés par les personnes qu'ils suivent

Liste des features :
- Afficher la liste touites - Aloys - Ronan
- Afficher un touite en détail - Ronan
- Afficher les touites d’une personne donnée - Benjamin
- Afficher les touites associés à un tag - Aloys
- Publier un touite - Aloys - Ronan
- La gestion des tags - Aloys
- Le mur d’un utilisateur - Benjamin
- Suivre des utilisateurs - Benjamin
- S’abonner à un tag - Benjamin
- Associer une image à un touite - Benjamin
- Page de connexion - Aloys
- Barre de recherche - Benjamin
Pour admin :
- Les influenceurs - Benjamin
